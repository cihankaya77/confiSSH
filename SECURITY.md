# Security policy

Only the latest release receives security fixes.

Do not open a public issue for a vulnerability. Use GitHub's **Security → Report
a vulnerability** option when it is enabled for the repository. Otherwise,
contact the repository owner through a private channel. Include only the minimum
information needed to reproduce the issue; never share a real SSH config,
password, private key, or access token.

ConfiSSH processes the user's SSH config files and backups. Replace all sensitive
values with examples before preparing tests or bug reports.
